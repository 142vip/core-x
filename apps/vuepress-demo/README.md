# vuepress-demo

`@142vip/vuepress`包的使用Demo演示

## 在线浏览

- Netlify： <https://apps-vuepress-demo.netlify.app>
- Vercel： <https://apps-vuepress-demo.vercel.app>

## 介绍

本 demo 仅依赖 `@142vip/vuepress`（另含演示用的 `@142vip/open-source`、`@142vip/utils`），用于验证开箱即用与功能正确性。

```bash
# 在项目根目录下载依赖
pnpm i

# 切换到vuepress-demo根目录
cd apps/vuepress-demo

# 本地启动
pnpm dev

# 本地编译
pnpm build
```
