### validation?

> `optional` **validation?**: `object`

定义于: node\_modules/.pnpm/typeorm@0.3.30\_ioredis@5.6.0\_mongodb@6.19.0\_mssql@11.0.1\_mysql2@3.15.1\_pg@8.11.3\_ts-node@10.9\_6zvdq3z7xgsf663jy3j6oymho4/node\_modules/typeorm/driver/mongodb/bson.typings.d.ts:352

Allows for opt-out utf-8 validation for all keys or
specified keys. Must be all true or all false.

#### utf8

> **utf8**: `boolean` | `Record`<`string`, `true`> | `Record`<`string`, `false`>

#### 示例

```js
// disables validation on all keys
 validation: { utf8: false }

// enables validation only on specified keys a, b, and c
 validation: { utf8: { a: true, b: true, c: true } }

 // disables validation only on specified keys a, b
 validation: { utf8: { a: false, b: false } }
```
